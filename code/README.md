# Кімната 3D — конструктор і розрахунок площі стін

Візуалізатор квартири з кількох кімнат (позиція, висота, рівень підлоги та
товщина кожної стіни — індивідуальні) з дверима/арками (відкоси, пороги),
електрикою (одинарні/подвійні/потрійні розетки, вимикачі, комбіновані,
виводи проводки), проводкою (повороти строго 90°, маршрути крізь стіни між
кімнатами), світильниками та предметами на стінах. Чистий JavaScript +
Three.js (без збірника), вкладки: **Файл**, **Конструктор**, **Проводка**,
**Розрахунки**. Розкрій ГКЛ має режим «Економія» — мінімум відходів із
використанням дрібних шматків.

## Запуск

Потрібен статичний сервер (через `file://` не працює — ES-модулі та importmap;
Three.js вантажиться з CDN, тож потрібен інтернет):

```bash
python3 -m http.server 8000
# відкрити http://localhost:8000
```

## Структура

- `index.html` — розмітка, importmap (three@0.160 з CDN), вкладки
- `app.js` — оркестрація: сцена, форми, взаємодія, збереження, рендер накладок
- `js/utils.js` — чисті хелпери (round2, hexToNum, colorHex, clampv)
- `js/drywall.js` — чистий алгоритм розкрою ГКЛ (tiling + cutting-stock оптимізатор
  з повторним використанням відрізків, зокрема вирізок дверей/арок)
- `style.css` — тема інтерфейсу

`js/drywall.js` не залежить від DOM чи Three.js — його можна тестувати окремо
(`node`), а `app.js` лише будує поверхні кімнати й передає їх у планувальник.
