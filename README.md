# Кімната 3D

Вебзастосунок для автоматизованого розрахунку та моделювання внутрішньобудинкової електромережі
і звіт з передкваліфікаційної практики до нього.

| Каталог | Вміст |
| --- | --- |
| [`code/`](code/README.md) | Застосунок (JavaScript, Three.js, без збірки) |
| [`docs/src/`](docs/src/README.md) | Звіт у LaTeX (XeLaTeX) |

Швидкий запуск застосунку:

```bash
cd code
py -m http.server 8010
```

Після цього відкрийте http://localhost:8010.
