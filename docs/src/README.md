# Звіт з передкваліфікаційної практики

Тема: «Вебзастосунок для автоматизованого розрахунку та моделювання внутрішньобудинкової електромережі».
Документ описує застосунок «Кімната 3D» з каталогу `code/` (3D-конструктор приміщень, трасування проводки,
розрахунок матеріалів, розкрій гіпсокартону). Оформлення базується на шаблоні
[nuwm-lab/latex-template](https://github.com/nuwm-lab/latex-template/tree/example/internship-practice).

## Структура

| Файл | Вміст |
| --- | --- |
| `main.tex` | Титульна сторінка (макрос `\makepracticetitlepage`) та підключення розділів |
| `sections/01_schedule.tex` | Календарний план проходження практики |
| `sections/01b_intro.tex` | Вступ |
| `sections/02_section.tex` | Розділ I: предметна область, розкрій листових матеріалів, аналоги, специфікація вимог, діаграма варіантів використання |
| `sections/03_section.tex` | Розділ II: архітектура (C4), модель даних, геометрична модель, трасування, розрахунки, розкрій ГКЛ, інтерфейс, верифікація, обмеження |
| `sections/04_conclusions.tex` | Висновки |
| `sections/05_list-of-references.tex` | Список використаних джерел (26 позицій) |
| `preamble/` | Пакети, стилі, макроси (`\settikz`, `\setscreenshot` додано для цього звіту) |
| `assets/` | Діаграми TikZ, контрольна сцена, скрипт перевірки, місце для скриншотів |

## Збірка

Компілятор **XeLaTeX** (шрифти лежать у `fonts/`):

```bash
latexmk -xelatex -pvc -f main.tex -outdir=build
```

Діаграми (`assets/*.tex`) є фрагментами TikZ і вбудовуються в документ командою `\settikz`,
тому окремо їх компілювати не потрібно.

виводиться рамка-заглушка. Додайте знімки з `http://localhost:8010`
(завантажте `assets/demo-project.json` кнопкою «Імпортувати»):

| Файл | Що зняти |
| --- | --- |
| `assets/ui-constructor.png` | Вкладка «Конструктор» із контрольною сценою |
| `assets/ui-wiring.png` | Вкладка «Проводка» з маршрутами |
| `assets/ui-calc.png` | Вкладка «Розрахунки» (результати та блок «Гіпсокартон») |
| `assets/ui-drywall.png` | Розкладка ГКЛ на 3D-моделі (прапорець «Показати розкладку на моделі») |

## Перевірка розрахунків

```bash
python assets/verify_calc.py
```

Скрипт незалежно перераховує показники контрольної сцени `assets/demo-project.json`;
значення збігаються з вкладкою «Розрахунки» застосунку (див. підрозділ 2.10 у звіті).
